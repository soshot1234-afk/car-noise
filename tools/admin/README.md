# 카스쿼드 관리실 — 처음 한 번만 하는 설정

관리실 주소: `https://carsquad.kr/admin.html` (테스트: `https://dream-test.carsquad.pages.dev/admin.html`)
예시 화면(가짜 숫자): 주소 뒤에 `?demo=1`

관리실은 지금 쓰는 구글 시트 「카롱도르 방문통계」의 Apps Script를 통해 움직입니다.
아래 4단계를 PC에서 한 번만 해 주시면 됩니다. 10분 정도 걸립니다.

## 1단계. 관리자 열쇠 정하기
- 8자 이상, 다른 곳에서 안 쓰는 문장으로 정해 주세요. 예) `빨간캐스퍼타고부산2026`
- 이 열쇠는 저장소·문서·카톡 어디에도 적지 마세요.

## 2단계. Apps Script에 열쇠 넣기
1. 구글 시트 「카롱도르 방문통계」 열기 → 메뉴 **확장 프로그램 → Apps Script**
2. 왼쪽 톱니바퀴 **프로젝트 설정** → 맨 아래 **스크립트 속성 → 스크립트 속성 추가**
3. 속성: `ADMIN_KEY` / 값: 1단계에서 정한 열쇠 → **스크립트 속성 저장**

## 3단계. 코드 붙여 넣기
1. 왼쪽 **편집기**(`< >`) → 파일 옆 **+ → 스크립트** → 이름 `admin` 입력
2. 새로 생긴 `admin.gs` 안의 내용을 다 지우고, 저장소의 `tools/admin/admin.gs` 내용을 통째로 붙여 넣기
3. 원래 있던 파일(보통 `Code.gs` 또는 `코드.gs`)을 열어서 두 군데에 한 줄씩 추가

```js
function doGet(e) {
  var adm = admGet(e); if (adm) return adm;   // ← 이 줄 추가 (중괄호 바로 다음 줄)
  ...원래 코드 그대로...
}

function doPost(e) {
  var adm = admPost(e); if (adm) return adm;  // ← 이 줄 추가 (중괄호 바로 다음 줄)
  ...원래 코드 그대로...
}
```

- `function doGet(e)` 괄호 안 이름이 `e`가 아니면(예: `request`) 줄 안의 `e`도 그 이름으로 바꿔 주세요.
- 위쪽 디스크 아이콘(저장) 누르기

## 4단계. 새 버전으로 배포 (주소는 그대로)
1. 오른쪽 위 **배포 → 배포 관리**
2. 지금 쓰는 배포 옆 **연필(수정)** → 버전: **새 버전** → **배포**
3. 권한 확인 창이 뜨면 동준 님 계정으로 허용

> **새 배포**를 누르면 주소가 바뀌어서 사이트 방문자 집계가 끊깁니다. 반드시 **배포 관리 → 수정 → 새 버전**으로 해 주세요.

## 확인
- `https://dream-test.carsquad.pages.dev/admin.html` 열기 → 열쇠 입력 → 현황에 오늘·총 방문자가 나오면 끝
- 시트에 「설정」 탭이 자동으로 생기고, 「한줄평」은 기존 「승인(Y)」 칸, 「제보」는 맨 끝 「처리」 칸을 씁니다.

## 열쇠를 잃어버렸거나 바꾸고 싶을 때
- 2단계 화면에서 `ADMIN_KEY` 값만 바꾸면 됩니다(재배포 필요 없음). 예전 열쇠가 들어 있던 휴대폰은 다음에 열 때 다시 묻습니다.
- 열쇠를 10번 틀리면 10분 동안 잠깁니다.

## 관리실이 하는 일
| 화면 | 하는 일 | 시트에 남는 것 |
|---|---|---|
| 현황 | `log` 탭으로 오늘·어제·7일·총 방문자, 오늘 많이 본 선수 | 없음(읽기만) |
| 한줄평 | 수락 = 「승인(Y)」에 Y, 거절 = N, 되돌리기 = 빈칸 | 「승인(Y)」 칸 |
| 바로 수정 | 공지 띠, 오늘의 선수, 깡통봇·한줄평 켜고 끄기, 점검 안내 | 「설정」 탭 |
| 제보·질문 | 오류 제보, 깡통봇 못 한 질문, 한줄평 신고 처리 표시 | 「제보」 탭 「처리」 칸 |

- 관리실에서 들어간 기기는 사이트 방문자 수에 넣지 않습니다.
- 사이트는 열릴 때 「설정」을 읽습니다(최대 1분 캐시).
