# 카스쿼드 인스타 이미지 도구 (AI 콘텐츠 담당용)

## 준비
1. 저장소 루트에서 `python3 -m http.server 8765` (백그라운드)
2. `node tools/insta/export.js` → `tools/insta/data2.json` 생성 (765종 차 데이터, OVR·능력치·MBTI 포함)

## 만들기
- `gen4.js`가 `vs(idA, idB, 표지문구, [[A쪽 이름, [장점3]], [B쪽 이름, [장점3]]])` 와 `top(...)`, `pg(슬라이드, i, n)` 를 export 해요.
- 새 게시물은 `tools/insta/week_YYYYMMDD.js` 같은 파일을 만들어 `require('./gen4.js')`로 vs/top을 불러 렌더링해요. (gen4.js 맨 아래 렌더링 코드 참고: 1080×1350, jpeg 92)
- 결과 이미지는 저장소에 커밋하지 말고 압축해서 사용자에게 보내요.
- 차 id는 data2.json의 `id` (예: dom21 캐스퍼, dom34 레이).

## 톤 (사용자가 직접 정한 규칙)
- 광고 같거나 AI 같은 말투 금지. 친구한테 말하듯 편하게 ("~더라고요", "여러분은 어느 쪽?")
- 캡션마다 ✏️ 줄 = 사용자가 직접 한마디 쓰는 자리 (예시 문장만 넣기)
- 숫자는 실측·공식 값만, 추정치는 쓰지 않기 (attrs 5번째 값이 1이면 추정)
- 인스타 이미지는 기존 어두운 톤 유지
- 업로드: 목요일 저녁 8~9시 = VS, 일요일 오전 = MBTI/TOP
- 해시태그 6개 안팎, 마지막은 #카스쿼드

## 이번 주 차 소식 (뉴스 담당)
- 템플릿: `news.js` → `newsPost({range, items, outro})`, `render(slides, 출력폴더)`. 예시: `news/2026-11-16.js` (1편)
- 실행: `NODE_PATH=$(npm root -g) node tools/insta/news/YYYY-MM-DD.js /출력/폴더`
- 사실 확인 규칙 (동준 님이 정한 것, 렉카 채널 금지):
  1. 1차 출처만: 제조사 보도자료·뉴스룸, 국토교통부/자동차리콜센터(car.go.kr), KNCAP, 공식 가격표. 언론 기사는 1차 출처를 찾는 길잡이로만.
  2. 숫자는 1차 출처 원문 그대로. 1차 출처를 못 찾으면 언론 2곳 이상이 같은 숫자일 때만 쓰고 출처 줄에 "언론 보도 교차 확인"이라고 밝힘. 하나라도 엇갈리면 그 숫자는 빼기.
  3. 유출·스파이샷·출시 '예정'·루머·커뮤니티발·해외 소식 단독 인용은 다루지 않음.
  4. 카드마다 출처 이름 + 날짜. 자극적인 제목(충격, 결국, 난리) 금지.
  5. 확인된 게 2개 미만이면 그 주는 쉼.
  6. 리콜은 '무상 점검 안내'로: 제목·태그에 '리콜' 대신 '무상 점검', "제조사 자발적 시정조치"라고 밝히고, 결함 내용은 국토부 공시 문구 범위 안에서만(공포 표현·추측·브랜드 비하 금지). 목적은 차주가 확인하게 돕는 것.
- 업로드 기록은 posted.md의 "뉴스" 목록에.
