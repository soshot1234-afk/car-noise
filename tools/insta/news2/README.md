# 이번 주 차 소식 — 새 스타일 (판매량 랭킹 디자인 기준, 2026-11-24~)

판매량 랭킹 게시물(11/23)과 같은 디자인 언어: 어두운 남색 배경, 위쪽 4색 바, 금색 킥 라벨+쪽수,
잘난체 큰 제목(금색 강조 `<b>`), 행 카드, 흰 원 안 제조사 로고 마크, 아래 CAR SQUAD 로고.

- 새 주차 파일: `2026-11-23.js`를 복사해서 `YYYY-MM-DD.js`로 만들고 items만 바꾸기
- 각 item: `brand`(로고 마크용: 현대·기아·제네시스·르노·쉐보레·KGM·BMW·벤츠·아우디·폭스바겐·볼보·테슬라·토요타·렉서스·포르쉐·미니 등, 없으면 글자 원), `tag`(신차 출시/사전예약/무상 점검(리콜)/가격/제도), `tagCls`('grn' 무상 점검, 'red' 주의), `short`(표지 한 줄, 20자 이내), `title`(두 줄, 둘째 줄 `<b>`), `lead`, `rows`(최대 5줄), `one`, `src`
- 실행: `NODE_PATH=$(npm root -g) node tools/insta/news2/YYYY-MM-DD.js /출력폴더` → 01.jpg~
- "⚠ 내용이 넘침" 경고가 나오면 문구 줄이기
- 차 사진 금지. 로고는 마크로만, 마지막 장에 상표 안내 자동 포함

## 차 사진 (2026-11-27 동준 님 결정: 뉴스에도 차 사진 넣기)
- 쓸 수 있는 사진: **제조사·수입사 공식 미디어센터/뉴스룸에서 보도용으로 배포한 사진만**. 언론사 사진, 블로그·커뮤니티 사진, 스파이샷, 렌더링 예상도, AI 생성 이미지는 금지.
- 사진 파일은 `photos/YYYY-MM-DD/파일명.jpg`에 두고 item에 `img: 'photos/YYYY-MM-DD/파일명.jpg'`, `imgCredit: '사진: OO 제공'`을 넣기 (사진이 lead 자리에 들어가고, rows는 3줄 이하로)
- 사진 위치 조정: `imgPos: '20% 60%'` (object-position)
- 무상 점검(리콜) 카드도 공식 보도사진이 있으면 쓸 수 있지만, 결함 부위를 강조하거나 손상된 차처럼 보이는 사진은 쓰지 않기
- 공식 사진을 구하지 못한 소식은 예전처럼 사진 없이 (lead 문장) 만들기
- `photos/manual/`에 동준 님이 직접 받아 둔 공식 보도사진이 있으면 그걸 먼저 쓰기 (파일명에 차 이름)

## 신차 집중 분석 (2026-11-27 동준 님 결정)
- 화제 신차(가격 공개·출시)는 차 소식 카드와 별도로 **한 차만 자세히** 게시물(10장 이하) + 릴스 1개를 따로 만든다.
- 예시: 게시물 `2026-11-27-e7.js`, 릴스 `reel/2026-11-27-e7.html`
- 구성: 표지(공식 사진 크게) → 한눈에 → 트림별 가격 → 트림별 추가 사양 → 제원 → 실내 → 2열·주행보조 → 색상·혜택·일정 → **카스쿼드 능력치 카드** → 끝
- 능력치: `carstats.js`로 사이트 계산식 그대로 계산(공식 제원만 넣기). 카드에 "공식 제원 N개 항목만으로 계산 · 실측 나오면 바뀔 수 있어요" 표기, 순위는 안 씀
- 사진: 제조사 보도자료 페이지의 보도용 사진(예: GM한국 뉴스룸 이미지 maxw_1600)만, `photos/날짜/차/`에 저장
