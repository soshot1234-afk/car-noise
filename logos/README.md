# 제조사 로고

화면에서 제조사를 가리키는 용도로만 써요. 모양이나 색을 바꾸지 말고, 홍보물에는 쓰지 마세요.
각 로고와 명칭은 해당 제조사의 상표예요. 카스쿼드는 제조사와 제휴 관계가 아니에요.

- SVG: Simple Icons (https://simpleicons.org, 아이콘 데이터 CC0. 상표권은 각 제조사에 있어요)
- PNG(제네시스·렉서스·링컨·GMC·로터스): car-logos-dataset (https://github.com/filippofilip95/car-logos-dataset), 원본 출처 carlogos.org
- 로고가 없는 제조사(BYD·KGM·지커·이네오스)는 이름만 보여 줘요. BYD는 데이터셋 로고가 옛 버전이라 뺐어요.
